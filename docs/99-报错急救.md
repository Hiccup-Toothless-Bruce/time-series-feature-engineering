# 99 报错急救：先在表里找，再决定要不要问人

## 0. 通用三步

1. **看最后一行**：错误类型 + 原因；
2. **看文件名和行号**：哪一行代码出错；
3. **看上下文**：出错前运行了什么命令、数据文件存在吗。

不要一看到红字就关掉终端。Python 的报错其实是在告诉你哪里出了问题。

---

## 1. 环境类错误

### `'python' 不是内部或外部命令`

**原因**：没装 Python，或者安装时没勾选 "Add Python to PATH"。

**解决**：

1. 重新安装 Python，勾选 "Add python.exe to PATH"；
2. 或者用 `py --version` 试试；
3. 装完重开 PowerShell。

### 虚拟环境激活失败：`Activate.ps1 cannot be loaded because running scripts is disabled`

**解决**：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\.venv\Scripts\Activate.ps1
```

### `ModuleNotFoundError: No module named 'pandas'`

**原因**：没装库，或者没激活虚拟环境。

**解决**：

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

如果提示 `pip` 不是命令，用：

```powershell
python -m pip install -r requirements.txt
```

### `pip` 下载很慢或超时

换国内镜像：

```powershell
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 2. 文件类错误

### `FileNotFoundError: [Errno 2] No such file or directory: ...`

**原因**：文件不存在，或者你在错误的文件夹运行脚本。

**解决**：

1. 用 `Get-Location` 确认在项目根目录；
2. 先运行生成数据的上一个脚本：

```powershell
python scripts\download_data.py
python scripts\04_load_clean.py
python scripts\05_time_features.py
python scripts\08_lag_rolling_features.py
```

3. 注意脚本的运行顺序：

```text
download_data → 04 → 05 → 06/07/08 → 09 → 10
```

### `UnicodeDecodeError`

**原因**：文件编码不是 UTF-8。

**解决**：本项目读写 CSV 时统一用：

```python
pd.read_csv(path, encoding="utf-8-sig")
df.to_csv(path, index=False, encoding="utf-8-sig")
```

### 终端中文乱码

```powershell
chcp 65001
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$env:PYTHONIOENCODING = "utf-8"
```

然后重新运行脚本。

### `PermissionError: [Errno 13] Permission denied`

**原因**：文件被 Excel/WPS 打开着，或者没有写权限。

**解决**：关闭正在打开该 CSV/图片的软件，再运行脚本。

## 3. pandas 类错误

### `KeyError: 'pm2.5'`

**原因**：列名写错了，或者数据没有读对。

**解决**：

```python
print(df.columns.tolist())
```

把列名打印出来，一个一个对照。注意大小写和空格：

- `pm2.5` 和 `pm25` 不是一回事；
- `TEMP` 和 `temp` 不是一回事。

### `SettingWithCopyWarning`

**原因**：你对一个"切片"做修改，pandas 不确定你改的是原表还是副本。

**解决**：在筛选后加 `.copy()`：

```python
subset = df[df["pm2.5"] > 100].copy()
subset["new_col"] = 1
```

### `ValueError: Input contains NaN`

**原因**：模型不允许特征里有缺失值。

**解决**：在训练前明确处理：

```python
df = df.dropna(subset=feature_columns + ["target"])
```

或者填补：

```python
df[feature_columns] = df[feature_columns].fillna(df[feature_columns].median())
```

但要注意：用中位数/均值填补时，只能从训练集算统计量，不能用测试集。

### `ValueError: could not convert string to float`

**原因**：特征里有字符串列，例如 `cbwd`（风向）。

**解决**：要么删掉这列，要么做独热编码：

```python
df = pd.get_dummies(df, columns=["cbwd"], drop_first=True)
```

### 关于 `NaN` 的一个提醒

`NaN`（Not a Number）表示缺失值。它和 0 完全不同：

- 0 是"知道它等于 0"；
- NaN 是"不知道它等于多少"。

不要把 NaN 直接改成 0 就完事，除非你确定 0 有物理意义。

## 4. 时间序列特有错误

### `shift` 之后出现一堆 NaN

**原因**：shift 会让开头几行没有值，这是正常的。例如 `shift(168)` 前 168 行都是 NaN。

**解决**：在建模前按用到的特征删除：

```python
df = df.dropna(subset=["pm25_lag168", "pm25_roll168_mean", "pm25_next"])
```

### 删缺失行之后，lag24 不是 24 小时前

**原因**：删行让时间轴断了。

**解决**：保持完整小时时间轴：

```python
df = df.set_index("datetime").sort_index().asfreq("h")
```

短缺口插值，长缺口保留 NaN，建模时再删除无法计算的行。

### 模型分数高得离谱（R² > 0.99）

**第一反应**：检查数据泄漏。

- 特征里有没有 `shift(-1)`、`center=True`；
- 有没有把目标列本身当特征；
- 有没有先在全量数据上算统计量再切分；
- 有没有随机切分时间序列。

本项目的 `_leaky` 特征就是反面教材，千万不要放进正式模型。

### `rolling` 结果前面全是 NaN

**原因**：窗口还没凑满。例如 `rolling(24)` 前 23 行都是 NaN。

**解决**：这是正常现象。可以用 `min_periods` 放宽，但要写清楚理由：

```python
df["roll24_mean"] = df["pm2.5"].rolling(24, min_periods=18).mean()
```

## 5. sklearn 类错误

### `ValueError: Found input variables with inconsistent numbers of samples`

**原因**：X 和 y 的行数不一样。

**解决**：打印行数：

```python
print(x_train.shape, y_train.shape)
print(x_test.shape, y_test.shape)
```

确保它们都来自同一个 `train` / `test` 表。

### `ValueError: Expected 2D array, got 1D array instead`

**原因**：sklearn 的模型要求 X 是二维表格（很多列），不是一维 Series。

**解决**：

```python
x_train = train[["pm25_lag1"]]   # 注意双层方括号
```

### 模型分数是负数

R² 负数表示模型比"永远猜平均值"还差。常见原因：

- 特征没有信息；
- 数据泄漏或切分错误；
- 训练集和测试集分布差异太大；
- 有极端异常值。

先回到基线：你的模型有没有打赢"平均值"和"持续法"？

## 6. Git / GitHub 类错误

### `fatal: not a git repository`

**原因**：当前文件夹没有初始化 Git。

**解决**：

```powershell
cd 正确的项目文件夹
git init
```

### `git push` 提示 `rejected` / `fetch first`

**原因**：GitHub 上的版本比本地新。

**解决**（确保本地修改已提交）：

```powershell
git pull --rebase origin main
git push
```

### `remote origin already exists`

**原因**：已经加过远程地址了。

**解决**：

```powershell
git remote -v
git remote set-url origin https://github.com/你的用户名/仓库名.git
```

### 推不上去，要输密码

GitHub 现在不支持账号密码，要用 Personal Access Token（PAT）。
看 `01-环境与工具.md` 的 5.4 节。

## 7. 什么时候该问人

自己尝试 3 次（每次换一种思路）还不行，就可以问。问的时候一次给全：

```text
1. 我运行了什么命令：
   python scripts\09_model_comparison.py

2. 完整报错（最后 15 行）：
   （粘贴）

3. 我已经试过：
   - 确认激活了 .venv
   - 重新跑了 08
   - 删掉了 __pycache__

4. 我的环境：
   Windows 11 / Python 3.14 / pandas 3.0.6
```

不要只发一句"为什么报错"，那样别人很难帮你。
